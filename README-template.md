### Lo que aprendí

En este reto aprendí lo básico de Tailwind CSS: cómo aplicar estilos directamente desde las clases en el HTML, sin escribir una hoja de estilos aparte. Por ejemplo, así se ve una tarjeta con clases de Tailwind:

```html
<div class="mx-auto max-w-xs rounded-2xl bg-white p-4 shadow-lg">
  ...
</div>
```
